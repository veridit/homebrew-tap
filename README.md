# veridit tap

Homebrew formulae and Scoop manifests for [veridit](https://github.com/veridit) tools.
Updated automatically by each tool's release workflow; do not edit by hand.

```sh
brew install veridit/tap/muninn                                   # macOS, Linux
scoop bucket add veridit https://github.com/veridit/homebrew-tap  # Windows
scoop install muninn
```
